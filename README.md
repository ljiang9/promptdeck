# PromptDeck — 个人提示词卡片库

一个**单文件**的提示词库管理工具：整个应用就是一个 `index.html`，双击即开，把你常用的 LLM 提示词做成一副可复用的卡片组（deck）。

## 为什么是单文件，而不是提示词 SaaS？

市面上的提示词管理工具要么是浏览器插件（绑死一个浏览器）、要么是 SaaS（你的提示词存在别人服务器上、还要登录付费）。PromptDeck 反其道而行：

- **零依赖**：无 CDN、无框架、无构建，纯原生 JS，28KB 左右一个文件
- **数据归你**：全部存在浏览器 localStorage，一键导出 JSON 备份
- **离线可用**：双击打开就能用，提示词本身不经过任何服务器
- **用完即走**：点开卡片 → 填变量 → 预览 → 复制，丢进任何 LLM 对话框

## 快速开始

1. 双击打开 `index.html`（或拖进浏览器）
2. 内置 8 张精心编写的卡片可直接用：论文润色、Code Review、旅行规划、SQL 生成、写作扩写、翻译校对、面试准备、正则解释
3. 点击任意卡片进入"使用"视图：正文里的 `{{变量}}` 会自动变成表单，填完实时预览，一键复制

## 功能

- **卡片管理**：新建 / 编辑 / 删除，标题、正文、标签、收藏星标
- **变量填充**：正文中的 `{{变量名}}`（支持中文变量名）自动解析为表单，实时预览填充效果
- **搜索与过滤**：按标题 / 正文 / 标签全文搜索，按标签筛选，按收藏筛选
- **导入导出**：整个卡组导出为 JSON（含备份与迁移）；单张卡片导出为 Markdown
- **中英双语界面**：一键切换
- **深色 / 浅色主题**：一键切换，自动记住
- **本地持久化**：localStorage 保存，刷新不丢

## 变量语法

在正文中使用 `{{变量名}}` 标记可填位置，例如：

```
请把{{文本}}翻译成{{目标语言}}，语气{{语气}}。
```

使用视图会自动生成三个输入框。重复出现的同一变量只生成一个输入框。
